# 随机小姐姐 · 播放器

一个单文件网页版随机短视频 / 图片播放器，打开就能看，不用安装，不用登录。

**在线体验：https://jgiosh1.github.io/SJXJJ/**

## 这是干什么的

点开页面就会随机播放一段短视频，点“换一个”换下一段。视频和图片都来自第三方公开接口，本仓库不存储、不上传任何视频和图片。

## 怎么用

1. 打开上面的在线地址（电脑和手机浏览器都能打开）。
2. 点 **“换一个”** 换一段，点 **“全屏”** 全屏看，**“自动连播”** 开关可以让视频播完自动换下一段。
3. 点顶部的接口名，可以从接口列表里换一个来源；每个接口旁边有个健康点，绿色表示最近比较稳，红色表示最近经常失败。
4. 手势（手机上）：左右滑切换接口，上下滑切换视频，双击暂停 / 播放。
5. 键盘（电脑上）：左右键切换接口，上下键切换视频，空格播放 / 暂停，F 全屏，Esc 关闭面板。

## 功能

- 33 个接口：27 个视频接口、6 个图片接口，接口列表里可以直接切换。
- 接口健康度：按最近的成功 / 失败情况给每个接口打点，失败的接口会自动跳到下一个可用接口。
- 今日统计：今日播放次数、切换次数、成功率，以及各接口的播放次数和成功率排行。
- 实时日志：点右上角的日志按钮，可以看到每次请求、成功、失败的记录。
- 历史回看：上下滑可以在最近看过的内容里前后翻，回到上一段不会重新下载。
- 全屏：支持原生全屏，手机浏览器 / WebView 里不支持原生全屏时会自动用页面内全屏兜底。

## 接口说明

接口全部是第三方提供的免费接口，稳定性由接口方决定，某个接口挂了是正常现象，播放器会自己跳到下一个可用接口，不会卡死。

目前接口列表里主要有：宇杰系列、万象、村嫂、WPON、KULEU、看戏仔、抖音、IQFK、QOC、小白、DUSHE、98QY、洛丽等，视频接口和图片接口在列表里有“视频 / 图片”标签区分。

完整接口地址见根目录 `index.html` 里的接口列表。

## 部署方式

本站点就是根目录的 `index.html` 这一个文件，通过 GitHub Actions 静态部署到 GitHub Pages，改动 `index.html` 并提交到 `main` 分支后会自动重新部署，不需要另外构建。

## 仓库结构

- `index.html`：线上正在跑的播放器（单文件，HTML / CSS / JS 都在里面）。
- `.github/workflows/deploy-static.yml`：把根目录 `index.html` 部署到 GitHub Pages 的工作流。
- `314052389634/`：早期用 Vite + React 做的旧版本项目文件，留着做参考，现在**不再**由 Pages 部署，不要按这个目录去理解线上页面。

## 注意事项

- 视频和图片内容均来自第三方接口，版权归原作者 / 原平台所有，如有侵权请联系接口方处理。
- 第三方接口随时可能失效、换域名或限流，遇到播不出来时先换个接口试试。
- 本项目仅供学习和娱乐使用。
